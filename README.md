# AdaptiveRunner

Brings adaptive triggers for yours flydigi apex 5 controller. This mod needs [Next Gen Gameplay by TheRealTen](https://mod.io/g/snowrunner/m/next-gen-gameplay) in order to work.

Requires Windows x64, Flydigi Space Station and .NET Desktop Runtime 8.

Download the [release](https://github.com/metalstress/AdaptiveRunner/releases/tag/v0.1.1-preview), extract it into `SnowRunner/Sources/Bin` and enable **AdaptiveRunner** in Spotter Launcher. It starts and closes with the game.

Right-click its tray icon to change feedback strength or exit. Work in progress.
